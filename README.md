# fns3-custom-charts
a repo that allows you to counvert osu!mania beatmaps to a format that can be read from the fns3 engine

# How to use

1. download the counverter + FTP installer from the releases page
2. get the osu!mania beatmap you want to counvert
3. extract the counverter
4. drag the drop the .osz file onto the counvert.bat
5. select the select the diffeculty
6. select scroll speed
7. type the name of the chart MUST BE EXISTING IN THE GAME (or use the e.g)
8. type the the name the will be used in naming the song MUST BE IN THE GAME (or use the e.g)
9. you will get a .zip file that has the chart file in the .backed format with the song

# Installing with FTP tool

1. drag and drop the zip file again in the counvert.bat
2. type ps3 ip address
3. enjoy

# Manual installation

1. extract the zip file onto a usb
2. copy the .backed file onto //dev_hdd0/game/NPXS00020/USRDIR/baked_files you must overwrite the original one
3. copy the .ogg files onto //dev_hdd0/game/NPXS00020/USRDIR you must overwrite the original one
4. enjoy
